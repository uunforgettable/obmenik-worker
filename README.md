# Помощник: как запустить свой кусок

Один раз:
1. Нажми зелёную кнопку **Use this template → Create a new repository**.
2. Назови репозиторий как угодно и выбери **Public** (публичный). Нажми **Create repository**.
3. Открой вкладку **Actions** и, если попросят, нажми **I understand my workflows, go ahead and enable them**.

Каждый раз, когда тебе называют номер куска (например `c0003`):
1. **Actions → Work chunk → Run workflow**.
2. Впиши номер куска и нажми зелёную **Run workflow**.
3. Всё. Через несколько часов в разделе **Releases** твоего репозитория появится результат, владелец проекта заберёт его сам. Компьютер при этом можно выключить.

Остановить запуск можно кнопкой **Cancel workflow** на странице запуска. Уже собранное всё равно сохранится.

Важно: не запускай один и тот же кусок дважды и не запускай кусок, который не назвали тебе.
