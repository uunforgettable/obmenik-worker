# Помощник: как запустить

Один раз:
1. Нажми зелёную кнопку **Use this template → Create a new repository**.
2. Назови репозиторий как угодно и выбери **Public** (публичный). Нажми **Create repository**.
3. Открой вкладку **Actions** и, если попросят, нажми **I understand my workflows, go ahead and enable them**.
4. Пришли владельцу проекта ссылку на свой репозиторий (вид `ник/название`), он добавит тебя в список.

Каждый раз, когда хочешь помочь:
1. **Actions → Work chunk → Run workflow → зелёная кнопка Run workflow**. Ничего вводить не нужно.
2. Запуск сам возьмёт кусок, назначенный тебе, и будет работать до 5 часов. Компьютер можно выключить.
3. Результат появится в разделе **Releases** твоего репозитория, владелец проекта заберёт его сам.

Если запуск пишет «Для тебя пока нет куска», подожди пару часов и запусти снова: новые куски выдаются автоматически.
Остановить запуск можно кнопкой **Cancel workflow**, уже собранное всё равно сохранится.
